# USD/JPY FX研究ツール Ver.0.1

DukascopyからUSD/JPYの5分足（2021/1/1〜2026/6/30）をダウンロードし、
バックテストに使えるCSVとして保存するツールです。
売買判定やバックテスト機能はまだ入っていません。データ整備が今回の役割です。

## ファイル構成

- main.py … 実行するのはこれだけ
- config.py … 期間・保存先・異常値の閾値などの設定
- fetcher.py … Dukascopyからのダウンロード処理
- quality.py … 欠損・重複・異常値のチェック処理
- data/ … 実行すると自動で作られる出力先

## 実行手順

1. Python 3.9以降をインストールする（すでに入っていればスキップ）
   https://www.python.org/ からダウンロードできます。
   インストール時に「Add Python to PATH」に必ずチェックを入れてください。

2. コマンドプロンプト（Macならターミナル）でこのフォルダに移動する

   cd フォルダを置いた場所/fx_tool

3. 必要なライブラリをインストールする（初回のみ）

   pip install -r requirements.txt

4. 実行する

   python main.py

これだけです。5年半分のダウンロードなので、回線にもよりますが
30分〜1時間程度かかる想定でいてください。

途中で止めても大丈夫です。月ごとにdata/chunksフォルダへ保存しながら
進むので、もう一度 python main.py を実行すれば取得済みの月は
スキップして続きから再開します。

## 出力されるファイル

data/USDJPY_5min_2021-2026.csv … 本体。列は以下の通りです。

| 列名 | 内容 |
|---|---|
| datetime_utc | 足の開始時刻（世界標準時） |
| datetime_jst | 足の開始時刻（日本時間） |
| open / high / low / close | 5分足のBid価格 |
| volume | ティックベースの取引量指標 |

data/quality_report.txt … 品質チェックのサマリー
data/gaps.csv … データが飛んでいる区間の一覧（週末休場かどうかの判定付き）
data/anomalies.csv … 異常値候補の一覧（急変動を含む）

## Pythonで読み込むとき

```python
import pandas as pd

df = pd.read_csv(

    parse_dates=["datetime_utc", "datetime_jst"],

df = df.set_index("datetime_jst")
print(df.head())
```

デイトレ検証は日本時間ベースで見ることが多いはずなので、
datetime_jstをインデックスにする形をおすすめします。

## 知っておいてほしい前提

価格はDukascopyのBid価格です。実際の約定はスプレッド分Askとずれるので、
バックテストを作る段階でスプレッド（USD/JPYなら0.2〜0.3銭程度）を
コストとして織り込む必要があります。Ver.0.2以降の話です。

volumeはFXに本当の意味での出来高が存在しないため、ティックの動きを
元にした活況度の指標です。「今日は動いている・いない」の相対比較には
使えますが、株の出来高と同じ感覚で絶対量として扱わないでください。

金曜21時UTC頃〜日曜21時UTC頃（日本時間で土曜早朝〜月曜早朝）は
市場が閉まっているため、この時間帯にデータがないのは欠損ではなく正常です。
quality_report.txtでは週末休場と本当の欠損を分けて集計しています。

異常値候補として出てくる「急変動」は、データエラーとは限りません。
雇用統計や為替介入のような本物の値動きも引っかかります。
勝手に削除はしていないので、検証で気になった足だけ個別に確認してください。

## バックテスト（Ver.0.2.1 / backtest.py）

Ver.0.1でCSVを作った後、同じフォルダで以下を実行します。

   python backtest.py

初期設定で5,400通り（6戦略 × 利確5 × 損切り4 × 時間帯9 × トレンド環境5）を
検証します。実データ規模で1分前後で終わります。

検証の考え方は「学習期間（2021〜2024）でランキングを作り、
同じ条件を検証期間（2025〜2026.6）に当てて再現するか確かめる」です。
学習で良くても検証で崩れるものは過剰最適化として自動で低評価になります。

出力は data/backtest/ に入ります。

| ファイル | 内容 |
|---|---|
| ranking.csv | 全パターンの成績。総合スコア順。判定列付き |
| adopted_candidates.csv | 判定が「採用候補」のものだけ抜き出したもの |
| overfit_examples.csv | 学習では良かったのに検証で崩れた失敗例 |
| detail_report.txt | 上位候補の年別・月別・曜日別・時間帯別の内訳 |
| trades_top1〜3.csv | 上位候補の全トレード履歴 |

判定列は4種類です。採用候補（両期間で利益が残り再現性あり）、
要注意（プラスだが優位性が弱い、または取引数不足）、
過剰最適化疑い（学習だけ良い）、不採用（検証で利益が残らない）。

総合スコアはPF単独ではなく、検証期間の総損益・PF・最大DDの小ささ・
最大連敗の少なさ・取引回数・学習と検証の乖離の小ささを重み付けした値です。
重みはbacktest.py冒頭のBTConfigで変えられます。

検証パターンを増やしたいときはBTConfigのweekday_filtersに
月〜金を追加すると32,400通り、さらにvol_filtersにATR条件を
追加すると129,600通りになります。処理時間は数分レベルです。

新しい戦略を追加したいときは、シグナル関数を1つ書いて
build_strategies()の辞書に1行足すだけです。フィルター条件の追加も
make_filter_masks()の辞書に1行足すだけで、総当たりに自動で組み込まれます。

## 研究モード（Ver.0.3 / research.py）

Ver.0.3では、`backtest.py`とは別に `research.py` を追加しました。
目的は自動売買ではなく、「岡畠AI研究所」として売買条件を大量生成し、利益が残る候補を探すことです。

### 実行前の確認

先にVer.0.1でデータCSVを作ってください。

```cmd
python main.py
```

以下のファイルができていればOKです。

```text
data/USDJPY_5min_2021-2026.csv
```

### 実行方法

同じフォルダで以下を実行します。

```cmd
python research.py
```

初期設定では最大5,000パターンを検証します。増やしたい場合は `research.py` 冒頭の `ResearchConfig.max_patterns` を `10000` などに変更してください。

### 出力ファイル

結果は `data/research/` に出力されます。

| ファイル | 内容 |
|---|---|
| research_ranking.csv | 全研究パターンのランキング |
| adopted_research_candidates.csv | 採用候補だけを抜き出した一覧 |
| overfit_research_examples.csv | 学習では良いが検証で崩れた過剰最適化例 |
| research_report.txt | 日本語の研究レポート |

### Ver.0.3で追加された考え方

- 学習期間は2021年〜2024年
- 検証期間は2025年〜2026年6月
- 学習だけ良い条件は過剰最適化として低評価
- シグナルは足確定時点、エントリーは次足始値
- 持ち越しなし
- 同一足で利確と損切りの両方に届いた場合は損切り優先
- 固定スプレッドではなく時間帯別スプレッドを使用

時間帯別スプレッドの初期値は以下です。

| 時間帯 | スプレッド |
|---|---:|
| 東京時間 9〜15時 | 0.2銭 |
| ロンドン時間 16〜21時 | 0.3銭 |
| NY時間 21〜24時 | 0.4銭 |
| その他 | 0.5銭 |

### よくあるエラー

#### `USDJPY_5min_2021-2026.csv が見つかりません`

先に以下を実行してください。

```cmd
python main.py
```

#### 実行が遅い

`research.py` の `ResearchConfig.max_patterns` を小さくしてください。

```python
max_patterns: int = 1000
```

#### 採用候補が出ない

失敗ではありません。現在の条件群では安定した優位性が弱いという研究結果です。
`research_report.txt` の「弱かった条件」「次に試すべき改善案」を確認してください。

### 注意

Ver.0.3は自動売買ではありません。あくまで研究用です。
採用候補は「すぐ使うルール」ではなく、「次に深掘りする条件」です。
実資金投入は、さらにデモ運用や追加検証をしてからにしてください。
